# Prompt Playground

## 理念

灵活、透明的 AI Chat 软件。

不添加复杂的提示词系统，所见（的消息）即所发（的请求体）。

所有提示词都视为同等地位，只是在显示方面有所区分。

消息的操作应留下存档（分支系统），方便复用和回退。

所有相似的功能应该保持统一的行为。

## UI

左侧管理会话（可折叠），右侧管理聊天。

### 聊天界面

空消息：显示一个占位符
系统消息：不分左右，使用相对不显眼的颜色
用户消息/助手消息：分右（用户）和左（助手）气泡
分隔符：提示分支节点的临界处

消息下方显示对该消息的操作按钮。

底边栏：更多选项（重新生成）+文本框+发送消息按钮

### 会话界面

用选项卡切换视图：

- 会话管理：以列表形式显示所有会话
- 分支管理：以树视图展开某一对话内的结构情况，点击可跳转至对应消息处（若不在当前分支，则自动切换）

为简化，仅将User Role及分支节点显示在树中。

## 消息管理

对于任意一条消息，可选择：

- 插入：在当前消息之前/后插入新消息
- 删除：删除后可选择恢复（显示成暗色）或彻底删除
- 修改：可修改文本、Role等。修改时会创建一个与当前消息平行的分支。
- 分支：从当前消息处创建新分支，新分支不包含任何消息
- 复制：将消息的全部内容复制至剪贴板

以上操作均不会主动发送请求。

全局模式：

- 排序：可拖拽不同消息，改变顺序（不能破坏树的结构）
- 批量选择：
  - 暂时用于批量删除
  - 多选消息
  - 选择之前/之后的所有消息
  - 设置筛选器（按Role选择）
  - 是否折叠显示：折叠后，不会显示消息的全部内容

其它功能：

- 添加消息：在最开始/最末尾添加一条新消息
- 发送消息：以 User Role 追加一条新消息，同时发送请求
- 重新生成：创建一个平行分支，重新生成最后一条助手消息（如果没有则直接生成，此时不创建分支）
- 流式响应：True/False
- 切换显示：Raw/Markdown渲染

## 分支管理

类比Git中的分支，这里将一个消息视作一个节点。

创建分支并不会固定先前的内容，上游节点的改动会影响之后的分支。

分支表现在聊天中时，是从根节点到当前分支的叶子节点的完整消息。在不破坏数据结构的情况下，允许跨分支操作。

对分支的操作，相当于对整个分支内所有消息的操作：

- 删除：如果有子分支，则不允许删除。否则删除整个分支上的所有节点（需提醒用户）
- 复制：创建一条平行分支，分支内容与当前分支一致

## 会话

会话代表一次独立的请求，其包含消息以及其它参数。

一个会话只能有一个根节点（消息）

功能：

- 克隆会话：可选择仅保留系统提示词
- 重命名：默认取消息的前几个字符作为标题
- 删除会话
