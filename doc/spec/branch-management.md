# 分支管理规格

## 树模型与当前分支

- 分支由消息树中的一条从虚拟根到叶节点的路径表示，不是与消息分离的实体。
- 消息节点可拥有多个子节点；拥有多个下游连接的普通消息即为分支节点。分支节点本身含有普通消息文本，摘要取自该节点自身内容。
- 创建分支不会冻结上游内容。未创建新分支的上游编辑直接修改共享节点，并影响其所有下游路径。
- 聊天区只展示当前路径；分支管理操作可定位到其他路径，但必须保持树约束。
- 同一分叉点下的直接子分支按创建顺序排列。该顺序同时用于分支树显示、聊天分隔符的 `XX/XX` 编号和箭头切换。

## 分支操作

### 创建空后继分支

- 从任一消息创建分支时，在该消息之后新建没有后续消息的路径，并立即将它设为当前分支。
- 分叉锚点和其上游消息由原路径与新路径共享；新路径随后新增的消息只属于新路径。
- 新建分支在对应分叉点的直接子分支列表中追加到末尾。

### 复制当前分支

- 复制当前分支会创建一条平行路径。
- 复制路径共享分叉点之前的上游节点；分叉点之后的每条消息均创建为独立副本，后续编辑不会改变原路径。
- 复制生成的分支在对应分叉点的直接子分支列表中追加到末尾。
- 完成后自动切换到副本路径。

### 删除分支

- 删除目标是所选分支入口消息及其全部后代真实消息，允许删除包含嵌套分支的完整后代子树。
- 确认前必须提示将删除的真实消息总数。计入正常、待删除、生成中、失败和已取消消息；不计虚拟根和临时错误记录。
- 删除当前分支后，优先切换到同一分叉点按创建顺序排列的下一个存活平行分支；没有下一个时切换上一个；均不存在时回到父节点路径。父节点为虚拟根时，当前路径为空。
- 删除非当前分支不改变当前路径。删除后必须保持树无环、每个真实节点只有一个父节点，且所有存活节点仍可从虚拟根访问。

## 分支管理视图

- 左侧栏“分支管理”选项卡显示当前会话的可展开树视图。
- 为降低复杂度，树中只显示 `user` 消息和分支节点；一条消息同时满足这两项时只显示一次。
- 每个显示条目使用其自身消息内容的前 20 个字符作为摘要。没有文本时使用空消息占位符。
- 展开分支节点可查看其分支内的 `user` 消息和嵌套分支节点。
- 点击树条目会滚动聊天区到对应消息；若条目不在当前路径，则先自动切换到其所在路径。
