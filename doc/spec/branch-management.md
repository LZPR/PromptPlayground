# 分支管理规格

分支树的紧凑行样式、展开状态、长文本截断规则与无障碍要求以 [UI 视觉规格](ui-style.md) 为准；工作侧栏和危险确认以 [交互规格](interaction.md) 为准。

## 树模型与当前分支

- 有消息的分支由消息树中的一条从虚拟根到叶节点的路径表示。空分支使用独立的持久化记录表示，记录稳定 ID、锚点节点（可为虚拟根）和同级 `branchOrder`；它不是消息，不显示在聊天消息列表，也不进入模型请求。
- 消息节点可拥有多个子节点；拥有多个下游连接的普通消息即为分支节点。分支节点本身含有普通消息文本，摘要取自该节点自身内容。
- 当前分支定位为真实消息叶节点或空分支 ID。选择空分支时，当前可见路径在其锚点结束；锚点是虚拟根时路径为空。
- 创建分支不会冻结上游内容。未创建新分支的上游编辑直接修改共享节点，并影响其所有下游路径。
- 聊天区只展示当前路径；分支管理操作可定位到其他路径，但必须保持树约束。
- 同一分叉点下的真实直接子消息与空分支记录按同级 `branchOrder` 合并排列。`branchOrder` 在分支入口创建时分配；空分支实体化后的首条消息继承该值，因此不会因较晚输入内容而改变位置。该顺序同时用于分支树显示、聊天分隔符的 `XX/XX` 编号和箭头切换。空分支的分隔符位于其锚点之后。

## 分支操作

### 创建空后继分支

- 从任一消息创建分支时，在该消息之后创建空分支记录，并立即将它设为当前分支。虚拟根也可作为锚点，以表达空会话的第一条独立路径。
- 分叉锚点和其上游消息由原路径与新路径共享；空分支不新增用户可见消息。
- 新建空分支在对应分叉点的直接子分支列表中追加到末尾，并获得下一个 `branchOrder`。
- 在空分支发送、在末尾添加消息、插入其首条消息或继续生成时，首条真实消息以空分支锚点为父节点创建，并在同一事务中删除空分支记录、将当前定位改为新消息叶节点。后续新增消息只属于该路径。
- 空分支的“继续生成”以锚点与其上游所有未删除消息作为模型上下文，在锚点后创建生成中的 `assistant` 消息。它不改变既有“重新生成”规则。

### 复制当前分支

- 复制当前分支会创建一条平行路径。
- 当前分支为空分支时，复制操作在同一锚点创建另一个空分支记录；不复制消息，也不请求模型。
- 复制路径共享分叉点之前的上游节点；分叉点之后的每条消息均创建为独立副本，后续编辑不会改变原路径。
- 复制生成的分支在对应分叉点的直接子分支列表中追加到末尾。
- 完成后自动切换到副本路径。

### 删除分支

- 删除真实分支的目标是所选分支入口消息及其全部后代真实消息，以及该子树锚定的全部空分支记录；允许删除包含嵌套分支的完整后代子树。删除空分支只移除该记录。
- 确认前必须提示将删除的真实消息总数。计入正常、待删除、生成中、失败和已取消消息；不计虚拟根、空分支和临时错误记录。删除空分支时数量为零，确认说明仅移除该空分支。
- 删除当前分支后，优先切换到同一分叉点按创建顺序排列的下一个存活平行分支；没有下一个时切换上一个；均不存在时回到父节点路径。父节点为虚拟根时，当前路径为空。
- 删除非当前分支不改变当前路径。删除后必须保持树无环、每个真实节点只有一个父节点，且所有存活节点仍可从虚拟根访问。

## 分支管理侧栏

- 工作侧栏“分支管理”面板显示当前会话的可展开树视图，顶部显示当前路径摘要与复制当前分支入口。当前会话不存在时显示空状态并禁用分支操作。
- 为降低复杂度，树中只显示 `user` 消息和分支节点；一条消息同时满足这两项时只显示一次。
- 每个显示条目使用其自身消息内容的前 20 个字符作为摘要。没有文本时使用空消息占位符。
- 空分支以“空分支”作为摘要，显示其在同一锚点的顺序，并提供继续生成、复制和删除等可用操作。
- 展开分支节点可查看其分支内的 `user` 消息和嵌套分支节点。
- 点击真实树条目会滚动聊天区到对应消息；若条目不在当前路径，则先自动切换到其所在路径。点击空分支先切换定位，再滚动到锚点消息。
