# 交互规格

本页定义跨视图复用的工作侧栏、浮层反馈、草稿保护和键盘交互。领域行为、数据约束与视觉令牌仍以各自规格及 [UI 视觉规格](ui-style.md) 为准。

## 工作侧栏

- 主工作区始终由聊天主区和工作侧栏构成；仅全局设置使用独立路由。会话管理与分支管理不再占用独立主内容页。
- 工作侧栏有三态：`collapsed` 为 64px，只在左上角显示一个带工具提示和可访问名称的展开按钮；不显示产品名、会话/分支标签、设置、背景面板或右侧边框。`expanded` 占可用视口宽度的三分之一，显示所选管理面板；`fullscreen` 占据整个工作区。全屏状态隐藏聊天但不得卸载聊天视图。
- 展开与全屏状态在顶部横向显示会话与分支标签；顶部提供折叠与全屏切换按钮。展开与全屏状态的底部固定显示设置入口。打开设置时必须先退出全屏或展开覆盖层，再显示独立设置路由，不能让设置内容被隐藏的聊天区遮挡。
- 窄屏使用覆盖式侧栏实现同样三个状态。默认折叠；非全屏展开态宽度为视口的三分之一，不遮盖剩余聊天界面；进入全屏态后占满视口。切换面板、关闭覆盖层或改变尺寸均不得丢失聊天滚动位置、底栏草稿、当前会话、当前分支或消息编辑草稿。
- 会话面板按 `updatedAt` 倒序显示。每行显示标题、当前/生成中状态和溢出菜单；面板顶部提供新建会话。溢出菜单包含重命名、克隆和删除。
- 分支面板以省略号菜单提供“克隆当前分支”，并显示当前路径摘要及可展开树。树条目保留既有摘要规则，额外显示空分支条目；空分支使用“空分支”标签而非消息文本。点击真实消息先切换到所属路径再滚动聊天；点击空分支切换至该空分支并滚动到锚点。每个可展开节点的展开按钮独立于省略号菜单。
- 当虚拟根包含多个直接子分支时，树显示不可删除、可展开的“起始分支”节点；其空文本首条消息显示“第一条消息”。虚拟根不提供删除，其他消息和空分支节点可删除自身及后续子树，并复用消息数量确认对话框。

## 对话框与编辑器

- 确认对话框桌面端宽度为 440px，表单对话框为 520px，均以 24px 内边距的标题、正文/字段和底部操作区纵向排列。底部操作区右对齐，取消在前、确认在后；危险确认使用危险色。窄屏宽度为视口减 32px，内容过高时仅对话框正文滚动，标题和操作区固定可见。
- 下列操作使用居中确认对话框：删除会话、删除分支、永久删除消息、清除 API Key，以及在有未保存消息编辑草稿时离开编辑器。对话框以明确标题、影响说明、取消按钮和非默认焦点的危险确认按钮组成；Esc、点击遮罩和取消均不执行操作。
- 删除会话必须输入完全匹配的当前会话标题后才能启用删除按钮。删除分支显示将永久移除的真实消息数。永久删除消息说明其直接子节点会重连至原父节点。清除 API Key 说明不会删除会话和其他偏好。
- 重命名会话使用小型表单对话框，预填标题并在输入为空白时显示字段错误。克隆会话使用小型表单对话框，提供“完整克隆”和“仅保留当前路径系统提示词”单选项，默认完整克隆。
- 新增、插入和修改消息共用非阻塞的底部停靠编辑器。编辑器替换聊天底栏但不添加遮罩、不锁定消息滚动；桌面端横向占满聊天主区、最小高度 220px、最大高度为主区的 45%，内部按“标题操作行、Role 与分支选项行、可增长文本框、右对齐操作行”排列。修改时额外显示默认开启的“创建新分支”开关。消息文本允许为空。
- 停靠编辑器提供全屏切换。窄屏默认全屏，桌面端默认停靠在聊天底部；全屏编辑器仍保留取消、保存和退出全屏入口。任一时刻只允许一个消息编辑草稿。
- 草稿经修改但未保存时，关闭编辑器、切换会话或分支、打开设置、导航离开聊天或关闭应用均显示“保存、放弃、继续编辑”对话框。保存失败时留在编辑器并显示可重试错误；放弃才可继续原操作。

## 反馈、等待与禁用

- 创建、重命名、保存、分支切换等成功操作直接更新界面，不显示干扰性成功提示；复制到剪贴板显示短暂的成功提示。所有持久化或网络失败均保留原数据或草稿，展示可读错误和重试入口。
- 异步操作在原触发位置显示加载状态并禁用重复触发；列表和聊天内容保留原尺寸。发送与生成的进度以助手消息和聊天底栏中的取消入口表达，不使用阻塞等待对话框。
- 一个会话存在活动模型请求时，禁用该会话的消息树变更、会话克隆和会话删除；允许查看、复制、切换会话及取消请求。侧栏会话行显示生成中状态，返回该会话后恢复生成进度。
- 待删除、恢复和分支切换属于可恢复或无数据丢失操作，不要求确认。输入校验、无可发送消息、到达分支切换边界和禁用操作必须在控件附近说明原因，不能只依赖颜色或悬停提示。

## 键盘、发送与滚动

- 桌面端聊天底栏在非输入法组合状态下以 Enter 发送；Shift+Enter 或 Ctrl+Enter 插入换行。移动端 Enter 始终插入换行，只能通过发送按钮发送。
- 发送前去除首尾空白仅用于判定是否为空；请求和持久化保留用户输入的原始文本。发送时冻结该次输入快照，成功追加 `user` 消息后清空底栏；失败则保留草稿。
- 聊天文本框可随内容增长至最大高度，超过后内部滚动。消息编辑文本框遵循同一增长规则，但不复用发送快捷键。
- 聊天视口处于底部附近时自动跟随新增或流式内容；用户主动向上滚动后停止自动滚动，并显示“回到最新消息”按钮。该按钮恢复底部定位与自动跟随。
