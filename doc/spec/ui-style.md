# UI 视觉规格

## 视觉定位

Prompt Playground 采用浅色、本地工作台风格：信息紧凑、层级清楚，并把注意力留给会话、分支和消息内容。白色表面与中性灰边界组织工作区；青绿仅用于主要操作、当前定位和键盘焦点。首版只提供浅色主题，不使用渐变、装饰插画或营销式大卡片。

## 设计令牌

实现应通过全局 CSS 自定义属性引用以下令牌，避免在组件中散落色值。

| 类别 | 令牌 | 值 / 规则 |
| --- | --- | --- |
| 字体 | `--font-sans` | `Inter`, `Microsoft YaHei UI`, sans-serif |
| 正文 | `--font-size-base` | 14px，行高 1.5 |
| 页面 | `--color-canvas` | `#F6F8FA` |
| 表面 | `--color-surface` | `#FFFFFF` |
| 主文本 | `--color-text` | `#1F2933` |
| 次级文本 | `--color-text-secondary` | `#52606D` |
| 弱文本 | `--color-text-muted` | `#7B8794` |
| 边框 | `--color-border` | `#D9E0E6` |
| 主色 | `--color-primary` | `#1F7A74` |
| 主色弱表面 | `--color-primary-subtle` | `#E3F2F0` |
| 成功 | `--color-success` | `#2F855A` |
| 警告 | `--color-warning` | `#A15C00` |
| 错误 | `--color-danger` | `#B42318`；弱表面 `#FDECEC` |
| 禁用 | `--color-disabled` | 文本 `#98A2B3`，表面 `#EEF1F4` |
| 焦点 | `--color-focus-ring` | `#1F7A74`，2px 外描边 |
| 圆角 | `--radius-control` | 6px |
| 圆角 | `--radius-message` | 8px |
| 阴影 | `--shadow-overlay` | 仅菜单、弹窗等浮层使用的轻阴影 |

正文以 14px 为基准。紧凑辅助文字可使用 12px，页面标题使用 20px；不随视口宽度缩放字体。所有文字容器必须允许长中文标题、URL 和未断行消息换行，不能遮挡相邻操作。

## 布局与导航

- 工作区由聊天主区和工作侧栏组成。侧栏折叠宽度为 64px，左上角只保留一个用于展开的图标按钮；不显示其他导航、设置、产品标识、面板背景或分隔边框。展开态占视口宽度的三分之一，包含产品名、横向会话/分支标签、管理面板和底部固定的设置入口。全屏态占据整个工作区。
- 宽度小于 768px 时采用覆盖式工作侧栏。侧栏默认收起，通过顶部菜单打开；非全屏展开态仍只占视口三分之一，全屏态占满视口。展开与全屏态的切换、关闭覆盖层及面板切换不得丢失当前会话、分支、编辑文本或聊天滚动位置。
- 所有触发导航、菜单、图标按钮和主要操作的可点击区域最小为 44px。图标按钮需要可访问名称；不熟悉的图标提供悬停工具提示。
- 当前导航项使用弱主色背景、主色文字和左侧强调线；悬停使用中性浅灰背景。禁用项不可触发导航，且保留可读的禁用原因。

## 组件与状态

- Element Plus 仅用于按钮、输入、选择、开关、菜单、对话框和反馈等基础控件；消息气泡、分支分隔符、消息树和聊天底栏由项目自定义。
- 表单控件使用白色表面、1px 边框和 6px 圆角。聚焦时显示焦点环；错误在字段下方显示简短说明，不只依赖颜色传达状态。
- 会话列表和分支树使用无嵌套卡片的紧凑行。选中、悬停、禁用、展开、空状态和加载状态必须有稳定尺寸，避免加载或内容变化造成布局跳动。会话行的生成中标识和空分支条目必须有文字说明。
- 菜单与居中对话框是唯一使用浮层阴影的区域；对危险操作采用明确的文字确认和危险色按钮，不把危险操作作为默认焦点。底部停靠消息编辑器属于聊天内容区，不使用浮层阴影或遮罩；全屏编辑器使用普通页面表面。
- 加载中保留原有内容并在操作处显示进度；异步失败使用错误文本和重试入口，不能只显示图标或颜色。

## 聊天呈现

- 聊天内容区使用页面底色，消息按路径纵向排列，单条最大宽度为内容区的合理比例并在窄屏扩展至可读宽度。
- `user` 消息右对齐，使用弱主色表面；`assistant` 消息左对齐，使用白色表面与中性边框；二者均为 8px 圆角。角色、状态和操作入口以文字或有名称的图标呈现。
- `system` 消息居中为低对比度中性条，不伪装成任一方向的对话气泡。空文本显示固定占位符。
- 待删除消息保持原位、降低不透明度，并用文字状态明确其不会发送。生成中、失败和已取消消息保留内容，显示对应状态和可用操作。
- 分支分隔符为低调的水平边界，包含直接子分支序号与前后切换按钮；无分叉不显示。箭头达到边界时禁用并保留稳定宽度。
- 临时错误记录使用弱红色表面和错误色边界，与三类 Role 消息区分；默认显示摘要，详情可展开，且不得出现 API Key 或认证信息。
- 聊天底栏固定在内容区底部，包含更多操作、可增长但有最大高度的输入框与发送/取消按钮。编辑消息时由底部停靠编辑器在同一位置替换底栏，编辑器的 Role 选择、分支开关和操作按钮在窄屏也必须完整可达。发送不可用时使用稳定的禁用样式，不额外占用提示文本行。

## 无障碍与响应式验收

- 正文、控件标签及状态文本与其背景至少满足 WCAG AA 对比度；焦点状态必须在键盘操作时清晰可见。
- 语义化使用 `nav`、`main`、`aside`、标题和按钮；路由当前状态通过 `aria-current` 表达。图标不能作为唯一信息载体。
- 在桌面与 375px 窄屏下，长中文标题、长消息和 200% 文本缩放均不得产生水平滚动、重叠或不可访问操作。确认对话框、侧栏全屏态和消息编辑器必须保留可见的取消/关闭与主要操作。
- 首版不提供深色主题；系统主题变化不改变视觉令牌。
