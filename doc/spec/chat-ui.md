# 聊天界面规格

聊天界面的共享颜色、字排印、控件状态、响应式阈值与无障碍要求以 [UI 视觉规格](ui-style.md) 为准。本页只定义聊天行为与其专属呈现规则。

## 布局与导航

- 桌面布局为可折叠左侧栏和右侧聊天区。左侧栏包含聊天、会话管理和分支管理入口，底部固定放置齿轮按钮作为全局设置入口。
- 窄屏布局保持会话管理、分支管理和聊天三个视图可达，以视图切换替代固定双栏；首次进入时左侧栏默认折叠，聊天编辑和生成状态在切换后保留。
- 全局设置以独立视图或面板打开；返回后保持当前会话、当前分支和聊天滚动位置。
- 当前分支切换后，聊天区展示从虚拟根后的首条真实消息到该分支叶节点的完整路径。目标消息不在当前路径时，从分支树跳转会自动切换到其所在分支并定位该消息。

## 消息呈现

- 空文本消息显示固定占位符，避免以空白气泡误导用户。
- `system` 消息不靠左或右对齐，使用较不显眼的中性样式。
- `user` 消息以右侧弱主色气泡展示，`assistant` 消息以左侧白色边框气泡展示。
- 当前路径经过分叉节点时，聊天区在对应边界展示分隔符。分隔符包含当前分叉点直接子分支中的 `XX/XX` 序号；没有分叉时不显示序号。
- 分隔符提供上一个和下一个分支的 `<>` 箭头。箭头按创建顺序切换当前分叉点的直接子分支，切换后保留共同上游消息并刷新当前分支路径。
- 每条消息下方提供与其状态兼容的操作入口；生成中消息显示生成状态，失败和已取消消息显示状态且仍可编辑或重新生成。
- 生成失败或中断时，在当前会话显示独立的临时错误气泡。该气泡使用区别于三种 Role 的红色弱化样式，默认展示错误摘要，并提供展开入口查看错误码、映射说明和安全原文；它不作为聊天消息、分支树节点或消息操作目标。
- 当前会话同时最多显示一条临时错误气泡。新的错误气泡替换旧气泡；当前会话出现任何新的可见消息时清除气泡。切换分支不清除气泡，应用刷新后气泡可消失。
- 待删除消息原位暗显，并清楚标识其不会被发送。

## 底栏与显示偏好

- 聊天底栏包含更多操作入口、文本框和发送按钮；更多操作中提供重新生成。
- 文本框内容为空时，发送按钮禁用并提示原因。当前分支没有可发送消息时，同样禁止发送并说明原因。
- 发送时新增一条 `user` 消息并立即请求模型；只有该流程会从底栏文本创建消息。
- `Raw`/`Markdown` 是持久化的全局显示偏好，应用于所有会话和消息。
- Raw 模式显示原始文本。Markdown 模式禁用内嵌 HTML；外部链接以新窗口打开。
