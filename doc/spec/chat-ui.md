# 聊天界面规格

聊天界面的共享颜色、字排印、控件状态、响应式阈值与无障碍要求以 [UI 视觉规格](ui-style.md) 为准；工作侧栏、对话框、反馈、键盘和草稿保护以 [交互规格](interaction.md) 为准。本页只定义聊天行为与其专属呈现规则。

## 布局与导航

- 聊天主区始终只负责展示当前路径、临时错误记录和聊天底栏。会话管理与分支管理在工作侧栏内打开，聊天区在侧栏展开或全屏后仍保持已挂载状态。
- 全局设置以独立视图打开；从侧栏进入时先退出侧栏全屏或展开覆盖层，设置路由只渲染设置页面，不得同时显示聊天页。进入或返回时遵循 [交互规格](interaction.md) 的草稿保护规则，并保持当前会话、当前分支和聊天滚动位置。
- 当前分支切换后，聊天区展示从虚拟根后的首条真实消息到该分支叶节点的完整路径。目标消息不在当前路径时，从分支树跳转会自动切换到其所在分支并定位该消息。

## 消息呈现

- 空文本消息显示固定占位符，避免以空白气泡误导用户。
- `system` 消息不靠左或右对齐，使用较不显眼的中性样式。
- `user` 消息以右侧弱主色气泡展示，`assistant` 消息以左侧白色边框气泡展示。
- 当前路径经过分叉节点时，聊天区在对应边界展示分隔符。分隔符包含当前分叉点直接子分支中的 `XX/XX` 序号；没有分叉时不显示序号。
- 分隔符提供上一个和下一个分支的 `<>` 箭头。箭头按创建顺序切换当前分叉点的直接子分支，切换后保留共同上游消息并刷新当前分支路径。
- 每条消息下方提供与其状态兼容、在悬停或键盘聚焦时可见的操作菜单。正常消息可修改、在前后插入、创建分支、复制和标记待删除；待删除消息可恢复、复制和永久删除；生成中消息只可查看、复制和取消；失败及已取消的 `assistant` 消息可修改、复制或重新生成。
- 修改、插入和添加由统一的底部停靠消息编辑器完成。修改操作的“创建新分支”选项默认勾选；编辑器的布局、全屏切换和未保存草稿处理以 [交互规格](interaction.md) 为准。
- 生成失败或中断时，在当前会话显示独立的临时错误气泡。该气泡使用区别于三种 Role 的红色弱化样式，默认展示错误摘要，并提供展开入口查看错误码、映射说明和安全原文；它不作为聊天消息、分支树节点或消息操作目标。
- 当前会话同时最多显示一条临时错误气泡。新的错误气泡替换旧气泡；当前会话出现任何新的可见消息时清除气泡。切换分支不清除气泡，应用刷新后气泡可消失。
- 待删除消息原位暗显，并清楚标识其不会被发送。
- 聊天页右上角的添加消息按钮展开菜单，提供“在开头添加消息”和“在末尾添加消息”；二者均打开统一消息编辑器。

## 底栏、发送与显示偏好

- 聊天底栏在同一水平行包含更多操作入口、文本框和发送/取消按钮；更多操作中提供“继续生成”和“重新生成”。继续生成不添加用户消息，直接基于当前路径创建下一条助手消息。
- 文本框内容为空白时，发送按钮禁用；不在底栏额外显示禁用原因文本。
- 桌面端 Enter 发送，Shift+Enter 与 Ctrl+Enter 换行；输入法组合期间 Enter 不发送。移动端 Enter 只换行，必须点击发送按钮。具体的草稿、快照、失败保留和自动增长规则以 [交互规格](interaction.md) 为准。
- 发送时新增一条 `user` 消息并立即请求模型；只有该流程会从底栏文本创建消息。当前分支为空分支时，新消息以该空分支锚点为父节点并使其实体化。
- 活动请求期间，底栏发送入口改为取消入口，且当前会话其他消息树变更不可用。用户切换到其他会话时，原会话继续生成并在会话侧栏显示状态。
- `Raw`/`Markdown` 是持久化的全局显示偏好，应用于所有会话和消息。
- Raw 模式显示原始文本。Markdown 模式禁用内嵌 HTML；外部链接以新窗口打开。
- 用户位于聊天底部时自动跟随新消息和流式内容；手动向上滚动后停止自动跟随，并显示“回到最新消息”入口。
