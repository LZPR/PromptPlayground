# Prompt Playground 产品规格

## 目的

Prompt Playground 是面向单个用户的、本地持久化的 AI Chat 软件。产品强调透明：聊天区中可见的、当前分支上未删除的消息，就是发送给模型接口的消息；应用不会隐式插入系统提示词、模板消息或其他消息。

本目录定义产品功能与交互。实现级技术选型、平台约束、数据访问边界和测试工具链见[技术架构与选型](architecture.md)。

## 共享术语与约束

### 会话与消息树

- 会话是一次独立聊天及其本地配置状态的容器。
- 每个会话都有唯一的**虚拟根节点**。它只用于维护树结构，不显示在聊天或分支树中，也绝不进入模型请求。
- 每条真实消息都是树节点，拥有固定 Role：`system`、`user` 或 `assistant`。除显示样式和发送时使用的 Role 外，三者具有相同的编辑和树结构地位。
- 消息树必须始终为无环树：一个真实消息只有一个父节点，可拥有多个子节点。任何删除、排序和跨分支操作均不得形成环、共享下游或其他图结构。
- 当前分支通常是从虚拟根到选中消息叶节点的一条路径；定位到空分支时，路径在空分支锚点结束。聊天区按该路径的消息顺序显示；分支分叉处显示分隔符。
- 主界面为聊天主区加可折叠工作侧栏；会话管理和分支管理在侧栏完成，只有全局设置使用独立视图。侧栏状态及窄屏行为以 [交互规格](interaction.md) 为准。
- 分支顺序按同级 `branchOrder` 固定排列。创建消息或空分支时分配该顺序；空分支实体化后的首条消息继承原顺序。分隔符显示当前分叉点直接子分支中的 `XX/XX` 序号；箭头只在该分叉点的直接子分支之间切换。
- 排序仅允许在分支节点之间的同一线性消息段内交换非分支节点，不得拖动分支节点或其子树，不得改变父子分支归属。

### 消息状态

- **正常消息**会显示，并按其 Role 参与请求。
- **待删除消息**仍在原位置显示为暗色，允许恢复、复制和在符合树约束时排序；它不进入请求体，也不作为批量筛选后的默认目标。
- **永久删除**会移除消息节点并将其下游节点重新连接到原父节点。虚拟根保证删除任何真实消息后树仍有唯一根。
- 生成中的、失败的和已取消的助手消息均是普通可见消息，带有相应状态标识。失败或中断时，助手消息保留已生成的文本。
- **临时错误记录**是当前会话运行期间的视觉提示，不属于 `system`、`user`、`assistant` 任一 Role，也不是消息树节点。它不参与请求、分支、复制、排序、批量选择、克隆或持久化，且不计入分支删除消息数。

### 全局规则

- 会话、消息树和偏好自动保存到本地，重启后恢复。应用不包含账户、云同步或多人协作。
- 发送、重新生成和空分支继续生成等请求类操作外，消息和分支管理操作均不得主动请求模型。
- 每个会话最多同时存在一个活动模型请求。
- 当前分支可定位到真实消息叶节点或空分支；空分支是持久化的分支定位记录，不是消息树节点，也不进入模型请求。
- 术语、确认方式和相似操作在各界面保持一致。

## 范围边界

第一版面向 Windows 和 Android 的单用户使用场景，两个平台保持核心功能对等，并提供桌面和窄屏布局。模型调用采用 OpenAI Chat Completions 兼容协议。认证、云端存储、多提供商管理、多人协作和云端后端不在本规格范围内；实现级技术约束见[技术架构与选型](architecture.md)。
