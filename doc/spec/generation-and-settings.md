# 生成与设置规格

设置表单、开关、对话框、加载和错误反馈的视觉状态与无障碍要求以 [UI 视觉规格](ui-style.md) 为准；确认、草稿保护和异步反馈以 [交互规格](interaction.md) 为准。

## 全局模型设置

- 全局设置从工作侧栏底部固定的齿轮按钮进入，以独立视图打开；返回后保持当前会话、当前分支和聊天滚动位置。
- 应用使用 OpenAI Chat Completions 兼容协议。
- 全局设置提供以下持久化字段：Base URL、API Key、模型名、温度、最大输出、流式响应开关和 Raw/Markdown 显示偏好。
- 配置只存在全局层级，所有会话共用；不支持会话级覆盖或多提供商预设。
- API Key 可在设置中替换或清除。清除前使用危险确认对话框，说明不会删除会话或其他偏好。应用在本地保存该设置，且不得在聊天消息、分支树或请求日志展示明文 Key。

## 请求构造与发送

- 点击发送时，将文本框非空白内容作为新的 `user` 消息追加到当前路径末尾，并立即发起请求。发送快捷键、输入法保护及草稿失败处理以 [交互规格](interaction.md) 为准。
- 请求的 `messages` 仅包含当前路径上所有未删除的真实消息，按聊天显示顺序排列，保留每条消息原始 Role 与文本。
- 虚拟根、空分支、待删除消息、其他分支消息和任何隐藏应用消息均不进入请求体。
- 发送前没有有效消息或输入为空时不创建消息、不发起请求，并在界面提示原因。

## 生成状态

- 流式响应开关是持久化的全局偏好。开启时，助手消息在令牌到达时增量更新；关闭时，在完整响应返回后更新。
- 同一会话有活动请求时，禁止再次发送或重新生成，并说明该会话正在生成。其他会话可独立发起请求。
- 生成期间，底栏发送入口改为取消入口。取消会中止请求、保留已收到文本，并把该助手消息标记为已取消。
- 请求失败或流式中断时，保留助手消息的已生成文本与失败状态，并在当前会话创建临时错误记录。用户可从该位置重新生成。
- 空分支的“继续生成”从其锚点及上游未删除消息构造请求，并在锚点后创建 `assistant` 消息；它不把空分支自身写入请求体。

## 临时错误记录

- 临时错误记录不属于三种固定 Role，不是消息树节点，也不参与请求、分支、复制、排序、批量选择、克隆或本地持久化。
- 每个会话同时最多保存一条运行期临时错误记录。新的错误会替换旧记录；当前会话出现任何新的可见消息时清除记录。切换分支不清除，应用刷新后不恢复。
- 错误摘要和展开详情根据错误码提供简要诊断：`400` 为“请求参数无效”，`401` 为“API Key 无效或缺失”，`403` 为“无权访问所选模型”，`404` 为“所选模型端点不存在”，`408` 为“请求超时”，`413` 为“请求内容过大”，`429` 为“请求过于频繁”，`500` 至 `599` 为“模型服务暂时不可用”。
- 未映射错误显示“错误码 - 安全原文”；没有错误码时显示“请求失败 - 安全原文”。展开详情显示错误码、映射说明和安全原文，不得包含 API Key、认证头或其他敏感配置。

## 重新生成

- 重新生成以当前路径最后一条 `assistant` 消息为目标。
- 若末尾是 `assistant` 消息，创建替换该消息的平行路径，再请求生成；原路径保持不变。
- 若当前路径末尾不是 `assistant` 消息，直接在末尾生成新的 `assistant` 消息，不创建分支。
- 重新生成遵守每会话一个活动请求的限制，并使用当前全局模型设置和流式偏好。
