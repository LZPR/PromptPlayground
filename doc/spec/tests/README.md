# 非 UI 数据结构测试规格

本目录定义 Prompt Playground 第一阶段的 TDD 测试。测试仅操作预构造的内存数据结构及其变换函数，不覆盖布局、交互控件、系统级依赖或渲染。

| 文件 | 覆盖范围 |
| --- | --- |
| [会话](session.test.md) | 会话初始状态、标题、克隆、删除。 |
| [消息管理](message-management.test.md) | 消息变换、删除、恢复、批量删除、排序。 |
| [分支管理](branch-management.test.md) | 路径、分叉、复制、删除、顺序和树不变量。 |
| [生成与设置](generation-and-settings.test.md) | 消息生成状态与全局设置对象变换。 |

## 约定

- 每个用例使用 Given/When/Then，测试名使用“`[领域] [动作] [结果]`”形式。
- 夹具使用静态 ID 与固定 `createdOrder`，不依赖随机数或时间。变换函数接收数据后返回新状态；除明确断言外，输入夹具不得被原地修改。
- 测试只验证领域状态。确认弹窗、禁用样式、提示文本、滚动定位、分支箭头和齿轮入口属于 UI，不在本目录覆盖。
- 成功用例和拒绝用例都必须断言完整状态：拒绝操作不得改变输入树、当前路径、消息状态或创建顺序。

## 标准夹具

| 名称 | 结构 |
| --- | --- |
| `emptySession` | 会话仅含虚拟根 `root-1`，标题为“新会话”。 |
| `linearSession` | `root-1 -> s-1(system) -> u-1(user) -> a-1(assistant)`。 |
| `forkedSession` | `root-1 -> s-1 -> u-1`，`u-1` 的直接子节点依创建顺序为 `a-1`、`a-2`。 |
| `nestedForkSession` | 在 `forkedSession` 的 `a-1` 后追加 `u-2`，`u-2` 的直接子节点为 `a-3`、`a-4`。 |
| `deletedSession` | 线性路径中 `u-1` 为待删除状态，其他节点正常。 |

## 共享不变量

每个会改变树的用例完成后，必须验证：

- 虚拟根存在且不可作为真实消息；真实消息均有固定 Role、一个父节点和零或多个直接子节点。
- 从虚拟根可访问每个真实节点；父子引用不存在环。
- 任一真实节点不得同时成为两个父节点的直接子节点；不同子分支不得复用同一个后代节点。
- 直接子节点数组按 `createdOrder` 或操作后定义的线性顺序稳定；未受操作影响的子树及节点 ID 保持不变。
- 空会话的当前路径为空；非空会话的当前路径从虚拟根开始，到一个有效叶节点结束。虚拟根不属于对用户可见的消息序列。
- 临时错误记录不属于树、Role 集合、当前路径或分支删除计数；它仅存在于运行期夹具，不出现在持久化夹具中。

## 待补充契约

现有规格定义分支为消息树路径，同时要求“从消息创建没有任何消息的后继分支”。只有消息节点、且分支不是独立实体时，空后继路径没有可区分的树表示。本目录保留该用例的测试目标，但在数据结构定义空分支的标识方式前，不为它设定可执行断言。
