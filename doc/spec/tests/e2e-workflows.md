# 浏览器工作流验收

本页定义 Playwright 对 UI 与交互的验收。领域状态的 Given/When/Then 测试仍见同目录其余文档。

## 工作侧栏

### `[工作侧栏] 三态 [保留聊天状态]`

- Given：已选会话、分支、底栏草稿和非底部聊天滚动位置。
- When：依次切换折叠、展开、全屏，并在 375px 视口中重复。
- Then：图标入口有可访问名称；会话/分支面板正确显示；返回聊天后会话、分支、草稿和滚动位置保持不变。

### `[会话侧栏] 操作 [在聊天旁完成]`

- Given：展开的会话侧栏。
- When：新建、选择、重命名、完整克隆与仅系统提示词克隆会话。
- Then：列表按最近活动排序，所有表单在对话框中完成，选择只更新聊天主区而不导航至独立会话页面。

### `[分支侧栏] 树操作 [定位与空分支]`

- Given：带嵌套分支和空分支的会话。
- When：选择真实树条目、选择空分支、复制当前分支和继续生成。
- Then：聊天定位到正确消息或锚点；空分支从未显示为聊天气泡或请求消息；继续生成后显示新的 assistant 气泡。

## 编辑与确认

### `[消息编辑] 停靠与全屏 [保护草稿]`

- Given：一条可编辑消息。
- When：打开编辑器、编辑 Role 和文本、滚动历史、切换全屏，再尝试关闭或切换会话。
- Then：编辑器替换发送栏但历史可滚动；窄屏默认全屏；未保存时可选择保存、放弃或继续编辑，且选择继续编辑不会发生导航。

### `[危险操作] 确认 [仅明确提交变更]`

- Given：可删除会话、分支、消息和已保存 API Key。
- When：分别打开确认框并使用 Esc、遮罩、取消与确认。
- Then：前三种关闭方式不改变数据；会话删除只有输入完整标题后可用；分支消息数和消息下游重连说明正确；清除 Key 不影响会话。

## 发送与滚动

### `[聊天底栏] 键盘 [桌面发送与移动换行]`

- Given：桌面和 375px 移动视口中的非空草稿。
- When：桌面按 Enter、Shift+Enter、Ctrl+Enter，并模拟输入法组合状态；移动端按 Enter 后点击发送。
- Then：桌面仅普通 Enter 发送，两个组合键换行，组合状态不发送；移动端 Enter 换行且只有点击发送会提交。

### `[聊天滚动] 新内容 [仅在底部跟随]`

- Given：流式生成中的聊天。
- When：处于底部接收内容，再向上滚动并继续接收内容，最后点击“回到最新消息”。
- Then：底部自动跟随；向上滚动后视口稳定并出现跳转入口；点击后回到底部并恢复自动跟随。
