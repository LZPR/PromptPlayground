# 分支管理数据结构测试

关联规格：[分支管理](../branch-management.md)。所有断言仅针对消息树、当前路径和直接子节点顺序。

## 当前路径与顺序

### `[分支] 选择叶节点 [解析唯一根到叶路径]`

- Given：`nestedForkSession`。
- When：选择叶节点 `a-4`。
- Then：当前路径为 `root-1 -> s-1 -> u-1 -> a-1 -> u-2 -> a-4`，不包含 `a-2` 或 `a-3`。

### `[分支] 直接子分支 [按创建顺序编号]`

- Given：`forkedSession`，`a-1.createdOrder < a-2.createdOrder`。
- When：读取 `u-1` 的直接子分支。
- Then：顺序为 `a-1`、`a-2`；`a-1` 的序号为 `1/2`，`a-2` 的序号为 `2/2`。

### `[分支] 切换直接子分支 [只替换分叉点以下路径]`

- Given：当前路径经过 `u-1 -> a-1`，`u-1` 的下一个直接子分支为 `a-2`。
- When：切换到下一个直接子分支。
- Then：共同上游 `root-1 -> s-1 -> u-1` 保持不变，当前路径改为经过 `a-2`；树不发生变更。

## 创建与复制

### `[分支] 创建空后继 [待定义空路径表示]`

- Given：一条已有后续消息的当前路径。
- When：从中间消息创建空后继分支。
- Then：测试应断言新分支可被唯一选中、与既有后续路径区分、且不新增用户可见消息。

> 此用例暂不定义树级断言。现有“分支是路径而非实体”与“空后继没有消息”无法同时表达；实现前需先定义空分支在数据结构中的标识方式。

### `[分支] 复制当前分支 [生成独立后续节点]`

- Given：`nestedForkSession`，当前路径为 `root-1 -> s-1 -> u-1 -> a-1 -> u-2 -> a-3`。
- When：复制当前分支。
- Then：分叉点之前的共享上游保持引用不变；分叉点之后复制出内容、Role、状态相同但 ID 不同的节点；修改副本节点不影响原节点；副本成为当前路径。

### `[分支] 新分支与副本 [追加创建顺序]`

- Given：分叉点已有两个直接子分支。
- When：依次创建新的分支和复制分支。
- Then：新增直接子分支依操作顺序追加在末尾，不重排已有子分支。

## 删除与不变量

### `[分支] 删除入口 [级联删除完整后代子树并统计数量]`

- Given：`nestedForkSession`，以 `a-1` 为所选分支入口，其后代为 `u-2`、`a-3`、`a-4`，其中 `a-4` 为待删除状态。
- When：请求删除该分支。
- Then：确认信息显示将删除 4 条真实消息；计数包含待删除消息，不包含虚拟根与临时错误记录。
- When：确认删除。
- Then：`a-1`、`u-2`、`a-3`、`a-4` 均被移除，`u-1 -> a-2` 路径保持不变，树满足共享不变量。

### `[分支] 删除当前分支 [优先切换下一个同级]`

- Given：分叉点按创建顺序有 `a-1`、`a-2`、`a-3` 三条直接子分支，当前路径经过 `a-2`。
- When：删除以 `a-2` 为入口的当前分支。
- Then：`a-2` 的完整后代子树被移除，当前路径切换到 `a-3`。

### `[分支] 删除当前分支 [没有下一个时切换上一个同级]`

- Given：分叉点按创建顺序有 `a-1`、`a-2` 两条直接子分支，当前路径经过 `a-2`。
- When：删除以 `a-2` 为入口的当前分支。
- Then：当前路径切换到 `a-1`。

### `[分支] 删除当前唯一分支 [回退父节点]`

- Given：当前路径为 `root-1 -> s-1 -> u-1 -> a-1`，`a-1` 没有平行分支。
- When：删除以 `a-1` 为入口的当前分支。
- Then：当前路径回到父节点 `u-1` 的路径，且 `u-1` 成为有效叶节点。

### `[分支] 删除虚拟根下唯一入口 [当前路径为空]`

- Given：当前路径为 `root-1 -> s-1 -> u-1`，`s-1` 是虚拟根唯一的直接子节点。
- When：删除以 `s-1` 为入口的当前分支。
- Then：`s-1` 及其后代均被移除，虚拟根保留，当前路径为空。

### `[分支] 删除非当前分支 [不改变当前路径]`

- Given：`forkedSession` 当前路径经过 `a-1`。
- When：删除以 `a-2` 为入口的分支。
- Then：当前路径仍经过 `a-1`，且 `a-1` 路径的节点与顺序不变。

### `[分支] 任意分支变换 [保持树而非图]`

- Given：`nestedForkSession`。
- When：依次执行复制、删除合法叶分支和切换分支。
- Then：每一步后均满足共享不变量，且任何真实节点都不被多个父节点引用。
