# 会话数据结构测试

关联规格：[会话](../session.md)。所有用例使用本目录的共享夹具与树不变量。

## 创建与标题

### `[会话] 创建 [只含虚拟根和默认标题]`

- Given：不存在会话数据。
- When：创建会话。
- Then：会话标题为“新会话”，仅含虚拟根，真实消息数为零，当前路径为空。

### `[会话] 首条非 system 消息 [生成一次自动标题]`

- Given：空会话。
- When：按顺序加入 `system` 消息和第一条 `user` 消息。
- Then：`system` 消息不改变标题；标题取该 `user` 消息前 20 个用户感知字符簇；标题已标记为自动标题已生成。

### `[会话] 自动标题 [不拆分用户感知字符簇]`

- Given：空会话及文本“19 个 ASCII 字符 + 一个由多个 Unicode 码点组成的可见字符 + 后缀”。
- When：将该文本作为第一条非 `system` 消息加入。
- Then：标题包含前 19 个 ASCII 字符及完整可见字符，不包含后缀，也不截断该可见字符内部的码点序列。

### `[会话] 手动重命名 [覆盖自动标题]`

- Given：已有自动标题的会话。
- When：设置自定义标题。
- Then：标题等于自定义值，之后任意消息变更均不更新标题。

## 克隆

### `[会话] 完整克隆 [复制独立消息树和当前路径]`

- Given：`nestedForkSession`，当前路径为 `root-1 -> s-1 -> u-1 -> a-1 -> u-2 -> a-3`。
- When：执行完整克隆。
- Then：新标题为“原标题 - 副本”；新树的结构、文本、Role、删除状态和直接子节点创建顺序与源树一致；新树所有真实节点 ID 与源树不同；新当前路径对应源当前路径；修改克隆树不改变源树。

### `[会话] 仅系统克隆 [提取当前路径并线性化]`

- Given：当前路径为 `system -> user -> system -> assistant` 的会话。
- When：执行仅系统提示词克隆。
- Then：新会话标题为“原标题 - 副本”；新树只含两条 `system` 消息，文本保持当前路径中的先后顺序；两条消息构成单一路径；不包含其他 Role、分支、生成状态或源节点 ID。

### `[会话] 仅系统克隆 [不读取非当前分支]`

- Given：有分叉的会话，非当前分支上存在额外 `system` 消息。
- When：执行仅系统提示词克隆。
- Then：新会话不包含该非当前分支的 `system` 消息。

### `[会话] 删除 [移除空分支记录]`

- Given：包含 `emptyBranchSession` 的会话集合。
- When：确认删除该会话。
- Then：目标会话、其所有真实消息及全部空分支记录均不存在；其他会话对象与顺序不变。

## 删除

### `[会话] 删除 [从会话集合移除完整树]`

- Given：包含多个会话的内存集合，其中目标会话包含嵌套分支。
- When：确认删除目标会话。
- Then：集合中不存在目标会话及其任何节点；其他会话对象与顺序不变。
