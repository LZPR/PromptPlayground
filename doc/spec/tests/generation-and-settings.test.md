# 生成状态与设置数据结构测试

关联规格：[生成与设置](../generation-and-settings.md)。本文件只验证状态对象变换，不构造请求、不调用外部服务，也不测试流式事件传输。

## 全局设置

### `[设置] 更新字段 [仅改变指定字段]`

- Given：包含 Base URL、API Key、模型名、温度、最大输出、流式开关和显示偏好的默认设置对象。
- When：逐项更新任一字段。
- Then：目标字段等于新值，所有未指定字段保持原值。

### `[设置] 清除 API Key [保留其他设置]`

- Given：各设置字段均有值的设置对象。
- When：清除 API Key。
- Then：API Key 为空，Base URL、模型名、温度、最大输出、流式开关和显示偏好均不变。

### `[设置] 切换显示与流式偏好 [独立变换]`

- Given：Raw 显示模式且流式关闭的设置对象。
- When：切换为 Markdown 和流式开启。
- Then：两个偏好均更新，连接配置字段不变。

## 助手消息生成状态

### `[生成状态] 开始生成 [创建生成中助手消息]`

- Given：当前路径末尾为 `user` 消息的会话。
- When：开始生成。
- Then：路径末尾追加 `assistant` 消息，状态为生成中，文本为空；会话活动生成标识指向该消息。

### `[生成状态] 完成生成 [保留文本并清除活动标识]`

- Given：包含生成中 `assistant` 消息和活动生成标识的会话。
- When：将消息置为完成并写入完整文本。
- Then：消息状态为完成、文本等于输入文本，活动生成标识为空。

### `[生成状态] 取消生成 [保留已有文本]`

- Given：生成中 `assistant` 消息已有部分文本。
- When：取消生成。
- Then：消息状态为已取消，已有文本不变，活动生成标识为空。

### `[生成状态] 生成失败 [保留已有文本]`

- Given：生成中 `assistant` 消息已有部分文本。
- When：将生成置为失败。
- Then：消息状态为失败，已有文本不变，活动生成标识为空，并在当前会话创建一条临时错误记录。

### `[生成状态] 生成中断 [保留已有文本并创建错误记录]`

- Given：生成中 `assistant` 消息已有部分文本。
- When：将生成置为中断。
- Then：消息状态为失败，已有文本不变，活动生成标识为空，并在当前会话创建一条临时错误记录。

## 临时错误记录

### `[错误记录] 已映射错误码 [生成摘要与详情]`

- Given：当前会话无临时错误记录。
- When：写入错误码 `404` 和安全原文。
- Then：记录摘要为“404 - 所选模型端点不存在”，详情包含 `404`、映射说明和安全原文。

### `[错误记录] 未映射错误码 [回退到代码和安全原文]`

- Given：当前会话无临时错误记录。
- When：写入未映射错误码 `418` 和安全原文。
- Then：记录摘要为“418 - 安全原文”。

### `[错误记录] 缺少错误码 [使用请求失败回退]`

- Given：当前会话无临时错误记录。
- When：写入没有错误码的安全原文。
- Then：记录摘要为“请求失败 - 安全原文”。

### `[错误记录] 详情 [隐藏敏感配置]`

- Given：错误原文包含 API Key、认证头和普通错误文本。
- When：创建临时错误记录。
- Then：摘要与详情保留普通错误文本，但不包含 API Key 或认证头值。

### `[错误记录] 新错误 [替换当前会话旧记录]`

- Given：会话 A 已有临时错误记录。
- When：会话 A 发生另一条错误。
- Then：会话 A 仅保留新错误记录。

### `[错误记录] 新可见消息 [清除当前会话记录]`

- Given：会话 A 已有临时错误记录。
- When：会话 A 新增任意可见消息。
- Then：会话 A 的临时错误记录被清除，消息树按新增消息规则变更。

### `[错误记录] 跨会话 [相互隔离]`

- Given：会话 A 和会话 B 均有不同的临时错误记录。
- When：会话 A 新增可见消息。
- Then：仅会话 A 的记录被清除，会话 B 的记录保持不变。

### `[错误记录] 刷新 [不恢复]`

- Given：内存会话带有临时错误记录。
- When：以仅包含持久化会话树和设置的夹具重建运行期状态。
- Then：重建后没有临时错误记录，原消息树、Role 集合和当前路径不变。

### `[错误记录] 创建与清除 [不影响树和分支删除计数]`

- Given：`nestedForkSession` 及一条临时错误记录。
- When：创建、替换或清除该记录，并计算以 `a-1` 为入口的分支删除数量。
- Then：树节点、当前路径、Role 集合与删除数量均不变。

### `[生成状态] 同会话重复开始 [拒绝]`

- Given：会话已存在活动生成标识。
- When：再次开始生成或重新生成。
- Then：操作被拒绝，原生成消息、活动标识和树均不变。

### `[生成状态] 不同会话开始 [状态相互独立]`

- Given：会话 A 正在生成，会话 B 无活动生成。
- When：在会话 B 开始生成。
- Then：两个会话各自持有不同活动生成标识，彼此的消息树和状态不互相改变。

## 重新生成的树变换

### `[继续生成] 空分支 [以锚点上下文创建 assistant]`

- Given：`emptyBranchSession`，当前定位为 `empty-1`，其锚点 `u-1` 及上游消息均正常。
- When：从空分支开始继续生成。
- Then：在同一变换中移除 `empty-1`，创建以 `u-1` 为父节点的生成中 `assistant` 消息，并将该消息设为当前叶节点和活动生成标识；请求消息来源只包含 `root-1 -> s-1 -> u-1` 上未删除的真实消息。

### `[重新生成] 末尾为 assistant [创建替换路径]`

- Given：当前路径末尾为完成、失败或已取消的 `assistant` 消息。
- When：开始重新生成。
- Then：原路径保留；从该助手消息之前的上游创建平行替换路径；新 `assistant` 消息状态为生成中并成为当前路径末尾。

### `[重新生成] 末尾不是 assistant [直接追加]`

- Given：当前路径末尾为 `system` 或 `user` 消息。
- When：开始重新生成。
- Then：不创建平行路径，直接在末尾追加状态为生成中的 `assistant` 消息。
