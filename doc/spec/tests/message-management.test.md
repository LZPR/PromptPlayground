# 消息管理数据结构测试

关联规格：[消息管理](../message-management.md)。所有操作只变换内存会话对象，不触发任何外部行为。

## Role 与新增消息

### `[消息] 创建 [接受三种固定 Role]`

- Given：`emptySession`。
- When：分别创建 `system`、`user`、`assistant` 消息。
- Then：三种消息均可成为真实消息节点，保留输入文本和 Role。

### `[消息] 在开头添加 [默认 system]`

- Given：`linearSession`。
- When：在当前路径最开始添加消息且不指定 Role。
- Then：新消息 Role 为 `system`，成为虚拟根的直接子节点，原路径首消息成为其直接子节点。

### `[消息] 在末尾添加 [默认 user]`

- Given：`linearSession`。
- When：在当前路径最末尾添加消息且不指定 Role。
- Then：新消息 Role 为 `user`，成为原叶节点的直接子节点并成为当前叶节点。

### `[消息] 插入 [默认 system 并保持线性连接]`

- Given：`linearSession`。
- When：在 `u-1` 前插入未指定 Role 的消息。
- Then：新消息 Role 为 `system`，父节点为 `s-1`，`u-1` 改为其直接子节点，其他节点和顺序不变。

## 编辑与删除

### `[消息] 编辑并创建分支 [保留原路径]`

- Given：`linearSession`，编辑目标为 `u-1`。
- When：以新的文本和 Role 编辑，并启用“创建新分支”。
- Then：`s-1` 保留原 `u-1` 子路径；新增编辑后节点为 `s-1` 的后续路径并保留编辑前上游；原 `u-1 -> a-1` 路径不变；新路径成为当前路径。

### `[消息] 编辑不创建分支 [原地更新共享节点]`

- Given：`forkedSession`，编辑目标为共享上游 `u-1`。
- When：以新文本和 Role 编辑，并关闭“创建新分支”。
- Then：`u-1` ID、直接子节点及创建顺序不变，所有经过 `u-1` 的路径读取到新文本和 Role。

### `[消息] 软删除与恢复 [不改变树边]`

- Given：`linearSession`。
- When：将 `u-1` 标记待删除，再恢复。
- Then：两次操作前后 `u-1` 的父节点、直接子节点、文本和 Role 均不变；状态依次为待删除、正常。

### `[消息] 永久删除 [重连直接子节点]`

- Given：`linearSession`。
- When：永久删除 `u-1`。
- Then：`u-1` 不再存在；`a-1` 的父节点变为 `s-1`；其余节点内容和顺序不变。

### `[消息] 永久删除首真实节点 [重连至虚拟根]`

- Given：`linearSession`。
- When：永久删除 `s-1`。
- Then：`u-1` 成为虚拟根的直接子节点，虚拟根仍存在，树满足共享不变量。

### `[消息] 批量删除 [只标记待删除]`

- Given：`forkedSession`，选择来自不同分支的 `u-1`、`a-1` 和 `a-2`。
- When：执行批量删除。
- Then：三个节点均为待删除状态，节点仍存在且所有树边不变；操作不永久删除任何节点。

## 排序

### `[排序] 线性段内交换 [重连同段节点]`

- Given：没有分支节点的线性段 `s-1 -> u-1 -> a-1`。
- When：交换 `u-1` 与 `a-1`。
- Then：路径为 `s-1 -> a-1 -> u-1`；三节点 ID、文本、Role 与状态保留；树满足共享不变量。

### `[排序] 含待删除节点的线性段 [允许交换]`

- Given：`deletedSession`。
- When：在同一线性段内交换待删除的 `u-1` 与相邻非分支节点。
- Then：顺序更新，`u-1` 仍为待删除状态。

### `[排序] 跨越分支节点 [拒绝且不改变树]`

- Given：`forkedSession`，`u-1` 为分支节点。
- When：尝试将 `s-1` 后的消息拖放到 `u-1` 之后的子分支线性段，或反向跨越 `u-1`。
- Then：操作被拒绝，整个树及当前路径保持不变。

### `[排序] 分支节点或子树 [拒绝拖动]`

- Given：`nestedForkSession`。
- When：尝试拖动 `u-1`、`u-2` 或任一包含后续节点的消息子树。
- Then：操作被拒绝，树和创建顺序保持不变。
