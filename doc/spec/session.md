# 会话规格

会话列表的密度、选中/悬停/加载状态、响应式行为与无障碍要求以 [UI 视觉规格](ui-style.md) 为准；工作侧栏、表单、确认和等待状态以 [交互规格](interaction.md) 为准。

## 会话生命周期

### 创建与默认标题

- 创建会话时生成空会话：仅创建不可见虚拟根节点，不自动新增真实消息。
- 新会话标题初始显示为“新会话”。首次出现非 `system` 消息时，自动取该消息文本前 20 个字符作为标题并保存。
- 自动标题只生成一次。之后修改首条非 `system` 消息不会改名；用户重命名后也不会再自动更新标题。

### 重命名与删除

- 用户可随时编辑会话标题。
- 删除会话前必须在危险确认对话框中输入完全匹配的当前标题。确认后永久删除会话、消息树、空分支记录及该会话关联的本地状态，不提供会话回收站。

### 克隆

- 克隆操作提供“完整克隆”和“仅保留系统提示词”两种内容范围，默认完整克隆。
- 完整克隆复制源会话整棵消息树及消息状态，新会话初始定位到源会话当时的当前分支。
- “仅保留系统提示词”只复制源会话当前路径上的全部 `system` 消息及其相对顺序；不复制其他 Role、非当前分支历史、空分支、生成状态或当前分支定位。
- 新会话标题使用“原标题 - 副本”。标题冲突不阻止克隆。
- 模型配置属于全局设置，不因克隆产生会话级副本。

## 会话管理侧栏

- 工作侧栏的“会话管理”面板以 `updatedAt` 倒序显示全部会话；每项展示标题、当前状态和生成中状态。选择某项会在聊天主区打开该会话及其已保存的当前分支。
- 面板顶部提供新建会话。每行溢出菜单提供重命名、克隆和删除；重命名与克隆使用表单对话框，克隆范围默认完整克隆。
- 当前会话生成时不可克隆或删除，菜单应说明原因。其余侧栏三态、窄屏行为与聊天状态保留规则以 [交互规格](interaction.md) 为准。
- 全局设置保持独立视图；进入与返回遵循草稿保护规则，且不改变当前会话或分支。

## 本地持久化

- 创建、改名、克隆、删除会话以及任何消息树变更都应自动保存。
- 应用启动时恢复会话列表、每个会话的树和当前分支、全局偏好以及全局模型设置。
- 用户可在设置中清除或替换 API Key；清除 Key 不删除会话或其他偏好。
