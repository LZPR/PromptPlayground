# 会话规格

会话列表的密度、选中/悬停/加载状态、响应式行为与无障碍要求以 [UI 视觉规格](ui-style.md) 为准。

## 会话生命周期

### 创建与默认标题

- 创建会话时生成空会话：仅创建不可见虚拟根节点，不自动新增真实消息。
- 新会话标题初始显示为“新会话”。首次出现非 `system` 消息时，自动取该消息文本前 20 个字符作为标题并保存。
- 自动标题只生成一次。之后修改首条非 `system` 消息不会改名；用户重命名后也不会再自动更新标题。

### 重命名与删除

- 用户可随时编辑会话标题。
- 删除会话前必须二次确认。确认后永久删除会话、消息树及该会话关联的本地状态，不提供会话回收站。

### 克隆

- 克隆操作提供“完整克隆”和“仅保留系统提示词”两种内容范围，默认完整克隆。
- 完整克隆复制源会话整棵消息树及消息状态，新会话初始定位到源会话当时的当前分支。
- “仅保留系统提示词”会复制源树中全部 `system` 消息及其相对顺序；不复制其他 Role、分支历史、生成状态或当前分支定位。
- 新会话标题使用“原标题 - 副本”。标题冲突不阻止克隆。
- 模型配置属于全局设置，不因克隆产生会话级副本。

## 会话管理视图

- 左侧栏的“会话管理”选项卡以列表显示全部会话。
- 每项至少展示标题和当前/最近活动状态；选择某项会打开该会话及其已保存的当前分支。
- 左侧栏可折叠，底部固定放置齿轮按钮进入全局设置。窄屏首次进入时左侧栏默认折叠，会话管理与聊天区切换显示，不能因布局改变丢失当前会话或分支选择。
- 全局设置以独立视图或面板打开；返回后保持当前会话、当前分支和聊天滚动位置。

## 本地持久化

- 创建、改名、克隆、删除会话以及任何消息树变更都应自动保存。
- 应用启动时恢复会话列表、每个会话的树和当前分支、全局偏好以及全局模型设置。
- 用户可在设置中清除或替换 API Key；清除 Key 不删除会话或其他偏好。
